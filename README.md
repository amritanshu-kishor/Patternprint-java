# Java Pattern Printing

A collection of Java programs for practicing different pattern-printing problems using loops, nested loops, numbers, alphabets, spaces, and conditional logic.

## Pattern Printing Problems

### 1. Alphabet Square – Question 1
Write a Java program to print an `n × n` square where each row contains the same uppercase alphabet corresponding to the row number.

**Example for `n = 4`:**
```text
A A A A
B B B B
C C C C
D D D D
```

**File:** `alphabetsq1.java`

---

### 2. Alphabet Square – Question 2
Write a Java program to print an `n × n` alphabet square where odd-numbered rows contain lowercase alphabets and even-numbered rows contain uppercase alphabets.

**Example for `n = 4`:**
```text
a a a a
B B B B
c c c c
D D D D
```

**File:** `alphabetsq2.java`

---
